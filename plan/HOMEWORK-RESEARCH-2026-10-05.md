# How teachers assign homework elsewhere - and what Anees copies (2026-10-05)

Medi: "please do some research on how teachers assign homework like this and see if theres a function we can copy".
Read 2026-10-05: Google Classroom help (Create an assignment) + Alice Keeler (how students turn in work), Quizlet Help
Center (Using Assignments), Duolingo for Schools (What are XP assignments), Preply Classroom features guide, italki forum.

| Platform | How the teacher assigns | What the student sees | What the teacher sees back |
|---|---|---|---|
| Google Classroom | one box: title, instructions, optional attachment, due date; Assign (or save a draft) | one card per task: Add or create -> Turn in | Turned in / Missing per student; returns it with a grade + comment |
| Quizlet | open a set -> Assign -> pick the mode (Learn / Test) -> due date | the set to study by the date | per-student progress on the assigned activity |
| Duolingo for Schools | XP (or a lesson) + a due date | a target to reach by the date | done / not done per student |
| Preply classroom | homework task written in the lesson room | the task list, marks it done | progress against the task list |
| italki | no built-in homework; tutors send tasks in chat, adults often decline homework | a chat message | the reply in chat |

The simplest proven pattern (all five share it): **one box, three fields, one list.**
1. The teacher fills ONE box: what to do (text), optional material (a set), a date it is for. No settings.
2. The student has ONE list: to do / done, each item opens where the work happens (type the answer, or the card set).
3. The teacher sees the same list from her side: done or not, and returns a verdict with a short comment.

Anees copies exactly that: Tutor page "Assign homework" = one box (kind: Translate sentence / Create sentence with / Answer
question / Cards for a lesson, the text, the lesson date). Student tab = his one list (to do / done, AI check, her verdict).

date" becomes "Cards for <date>: <set>". Nothing is sent to Amal by code (AM-01); Medi sends her the Tutor link as always.
