# Levantine Arabic Curriculum Index — 2026-10-06

## 5-line summary
1. **Best machine-readable Palestinian sources for Anees:** Maknuune (36k-entry Pal lexicon, TSV), kaikki/Wiktionary South Levantine (3,002 words, JSONL, 18 MB), Curras (56k-token annotated Pal corpus, CC BY 4.0). Everything else is PDF/app/video = partly or not ingestible.
2. **Best syllabi to copy a grammar order from:** Lebanese Arabic from Scratch (public TOC PDFs), Routledge *Colloquial Arabic (Levantine)* (13 units → B1), SOAS Beginners 1-3 page. Elihay *Speaking Arabic* is the Palestinian gold standard (50 lessons, 2,500 words) but transliteration-only and paper.
3. **No public Levantine-specific frequency list exists.** Closest: CAMeL DA frequency list (all dialects mixed) and Lingualism's 4,500-word thematic vocab (Lebanese, $18, not open).
4. **Free Jordanian/Palestinian listening with transcripts:** The Arabic We Speak (Amman, free worksheets), Omar Nassra podcast (A1-B1 labelled), Shababeek free audio+worksheets, Learn Arabic with Maha (YouTube, Pal).
5. **Licensing:** only Wiktionary/kaikki (CC BY-SA), Curras (CC BY), Peace Corps (US-gov public domain), Wikibooks/Wikipedia (CC BY-SA), UD treebank (CC BY-SA) are safe to ingest and redistribute. MADAR is research-only. Commercial books/apps = read, don't copy.

## Top 5 recommendations
1. **Maknuune (#31)** — ingest the TSV as Anees's secondary Palestinian lexicon: gloss, root, plural, transcription for ~17k lemmas; use it to auto-check Amal's words and fill plurals/feminines.
2. **kaikki South Levantine JSONL (#33)** — 18 MB, CC BY-SA, one JSON per word with IPA, forms and topic tags; the easiest machine-readable "verb forms + examples" feed for the flashcard engine.
3. **Lebanese Arabic from Scratch TOC + Routledge Colloquial Levantine (#11, #8)** — steal the grammar ORDER (table above) for Anees's grammar tracker; Amal can map her lessons onto it without changing her method.
4. **The Arabic We Speak + Shababeek free audio (#43, #30)** — Jordanian/Palestinian listening with transcripts and worksheets, free for educational use; ready-made homework material for Amal.
5. **Elihay Speaking Arabic + Olive Tree (#1, #2)** — the Palestinian canonical course; buy the paper set for Amal/Medi as the reference, don't try to ingest it.
